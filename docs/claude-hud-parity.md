# Claude HUD parity audit

Audit baseline: `jarrodwatts/claude-hud` 0.5.0, commit `1a73dd7c1835864e4040781f8c824bbd64d6dc66` (2026-07-16). Codex compatibility is exercised against representative rollout fixtures from CLI 0.144.1 and 0.153.2; `doctor` also probes the live log schema instead of assuming one fixed tracing layout.

Codex HUD reproduces the upstream experience using the data that Codex CLI actually records. Claude Code has a native arbitrary statusline process; Codex currently does not, so the equivalent persistent surface is a managed terminal pane: a native cmux split when available, with tmux as the compatibility backend. Codex HUD never invents values for telemetry that Codex does not expose.

## Fidelity boundaries

- The persistent HUD never renders user prompts or assistant message bodies. It counts turns without retaining their bodies; the opt-in conversation navigator reparses the active local rollout only after the user focuses the HUD and opens it. It never reads tool output bodies, API keys, or access tokens.
- Navigator message bodies remain in renderer memory only while needed and are not written to HUD configuration, copied to a second transcript, or sent over the network.
- Without `sqlite3`, session titles are omitted and API-key/custom-provider endpoint labels remain conservative. A session with locally verified ChatGPT authentication may still use its own rollout quota events without endpoint-log evidence.
- Endpoint resolution reads only request URLs and resolved `base_url` values from Codex's log database, never request or response bodies. Confirmed normalized origins are stored privately per session so log pruning or a new HUD process does not make trusted quota disappear. When neither log evidence nor an unchanged provider configuration can prove an API-key endpoint, the HUD shows generic `API Key`.
- Credential-bearing relay balance queries require HTTPS except on loopback development origins, and the Presentation preset hides screen-sharing-sensitive fields.
- `showCost` remains accepted so an upstream-style config does not break, but it is intentionally hidden until Codex provides authoritative cost data.
- The dedicated pane consumes terminal rows, unlike Claude Code's native footer. It starts at 5 rows, then fits the complete rendered content up to the `CODEX_HUD_HEIGHT` / `--hud-height` maximum (default 30 rows).
